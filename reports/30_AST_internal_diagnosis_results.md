# AST 内部诊断结果：局部 patch、中间层与预训练领域差异

## 结论摘要

本轮完成新阶段计划的第一部分：只使用 inner-training 与 inner-validation roles，在 3 个
repeats、每个 4 folds 上诊断 AST 的局部区域、中间层表示和有限领域适配。12 个诊断 split
合计包含 204 次验证猫评价；outer-test 全程保持未访问。

| 诊断轴 | 核心结果 | 预设完整支持规则 | 当前信息 |
| --- | --- | --- | --- |
| 中间层 | 最佳中间层 L11 为 0.7353，final L12 为 0.7649，差 `−0.0297`，3/12 splits 提高 | 未通过 | 年龄信息总体随层加深增强，final layer 是最强独立读出 |
| 局部 patch | 中频区域单独达到 0.7437，距 global 0.7649 为 `−0.0213`；遮蔽中段时间使真实类别概率平均下降 0.1781，12/12 为正 | 未通过，两个条件接近门槛 | AST 稳定依赖中段时间信息，中频区域保留了大部分年龄判别信息 |
| 预训练领域差异 | Last-2 由 0.7189 提至 0.7439，平均 `+0.0249`；5/12 提高、3/12 持平、4/12下降；animal CE 变化 `+0.0023` | 未通过 | 有限适配改善分类中心与 senior recall，跨 split 方向仍混合 |

三条轴都没有达到各自完整支持规则，因此诊断记录保持 `awaiting_team_selection`，当前尚未
分配新的 IDEA 编号。三条证据的研究价值并不相同：**局部 patch 是目前最强的机制线索**，
因为区域 probe 与输入遮蔽给出两种相互呼应的结果；有限领域适配是第二候选，它的平均分类
结果明显提高，但稳定性和概率指标仍需在参数量对照中解决；独立中间层读出可以暂缓。

如果团队决定继续一个单模块，我建议优先选择“保留 final AST 主路径、针对中频与有效时间
区域加入轻量局部分支”，并将 Last-2 的 mixed signal 用作领域适配方向的支持背景。这个
方向不同于 IDEA-052 的全时间均值 residual：新模块应保留局部位置结构，并避免再次把所有
时间 token 直接压成一个均值。

## 1. 诊断范围与方法

本轮先提取六组局部区域表示：前段、中段、后段时间，以及低频、中频、高频。每组都是
AST 最后一层 patch tokens 的受控区域平均，最终形成 `792 × 6 × 768` 区域特征。另对六个
输入区域执行均值替换并重新通过 AST，形成 `792 × 6 × 768` 遮蔽特征。

中间层与区域信息统一使用 multinomial logistic regression probe。每个 split 的 scaler 和
class-balanced sample weights 只根据 inner-training calls 计算；验证时先预测 call 概率，
再平均同一只猫的概率。相同 probe 结构让层与区域之间的结果可以直接比较。

领域轴比较两种训练状态：

- Frozen：冻结 AST，只训练 `768 → 128 → 3` head，共 99,075 个可训练参数；
- Last-2：更新 AST 最后两个 Transformer blocks、最终 LayerNorm 和同一个 head，共
  14,276,355 个可训练参数。

两者使用 IDEA-056 确定的猫级验证 CE 选择 epoch，并采用修正后的 global class weights 与
固定 denominator 32。该比较用于定位领域适配信号；参数量匹配对照将在方向获选后的单模块
阶段加入。

结果呈现清楚的总体趋势：浅层从声学局部模式开始，随着 Transformer block 增加，年龄类别
的线性可读性逐步增强；第 9 层出现一次回落，随后第 10–12 层恢复，最后层获得最高的四项
主要分类指标。

最佳中间层 L11 相对 L12 的平均 macro F1 低 0.0297，只在 3/12 splits 提高。204 次验证猫
评价中，两层共同判对 142 次；L12 独有 11 次正确，L11 独有 5 次正确。L11 仍含有少量
互补错误，但独立读出优势较小，也缺少跨 split 稳定性。该结果解释了此前全 12 层 scalar
fusion 的下降：把所有层共同混入会稀释 final layer 已经形成的高层判别表示。

本轮因此暂缓“单独使用中间层”或“平均融合全部层”。未来局部分支如需读取中间层，可以
优先把 L10/L11 当作补充来源，同时保留 L12 主路径。

## 3. 局部 patch 诊断

### 3.1 六个区域各自包含多少年龄信息

| 区域表示 | Animal macro F1 | Balanced accuracy | QWK | 与 global F1 差 |
| --- | ---: | ---: | ---: | ---: |
| 前段时间 | 0.6688 | 0.7028 | 0.4828 | −0.0962 |
| 中段时间 | 0.6716 | 0.7056 | 0.5536 | −0.0933 |
| 后段时间 | 0.6676 | 0.6889 | 0.5131 | −0.0973 |
| 低频 | 0.6651 | 0.6833 | 0.5063 | −0.0998 |
| **中频** | **0.7437** | **0.7583** | **0.5995** | **−0.0213** |
| 高频 | 0.7035 | 0.7167 | 0.5597 | −0.0615 |
| Global AST | **0.7649** | **0.7778** | **0.6239** | 0 |

中频区域的 0.7437 明显高于低频 0.6651 和高频 0.7035，只比完整 global embedding 低
0.0213。这说明 AST 的年龄判别信息在频率轴上具有明显集中区域，单独使用中间四个 AST
frequency positions 已经保留 global probe 的大部分分类能力。

中频 probe 与 global probe 共同判对 138 次；global 独有 15 次正确，中频区域独有 7 次
正确。局部区域确实能修正部分 global 错误，同时其新增纠正少于丢失的 global 正确结果。
预设规则要求与 global 的差不低于 −0.020、区域独有正确至少 10 次；实际分别为 −0.0213
和 7 次，因此完整支持条件以很小的性能差距和 3 次互补事件之差关闭。

### 3.2 遮蔽敏感性

| 被均值替换的输入区域 | Macro F1 平均下降 | 真实类别概率平均下降 | 概率下降的 splits |
| --- | ---: | ---: | ---: |
| 前段时间 | 0.1999 | 0.1650 | 10/12 |
| **中段时间** | **0.2540** | **0.1781** | **12/12** |
| 后段时间 | 0.1888 | 0.1443 | 11/12 |
| 低频 | 0.1076 | 0.0394 | 10/12 |
| 中频 | 0.0964 | 0.0489 | 9/12 |
| 高频 | 0.0894 | 0.0389 | 9/12 |

中段时间区域的输入结构被均值替换后，真实类别概率在 12/12 splits 都下降，平均下降
0.1781；猫级 macro F1 平均下降 0.2540。前段和后段也有明显作用，表示 AST 会综合一条
有效叫声内部的时间变化，中段贡献最稳定。

遮蔽效应与 call duration、有效帧比例、平均绝对 fbank 值和 fbank 标准差的平均 Spearman
相关系数绝对值都低于 0.08。局部敏感性因此主要反映时间—频率结构变化，而非简单由叫声
较长、padding 较少或能量较大驱动。

区域 probe 回答“一个区域自身有多少年龄信息”，遮蔽回答“完整 AST 是否依赖该区域”。两种
结果共同指向中频与中段时间，但目前只证明 AST 已经使用这些区域；局部分支能否提取 global
之外的稳定增量，需要下一阶段的 M1 与参数量匹配 C1 直接验证。

## 4. 预训练领域差异诊断

| 状态 | Macro F1，mean ± SD | Balanced accuracy | QWK | Accuracy | Animal CE |
| --- | ---: | ---: | ---: | ---: | ---: |
| Frozen | 0.7189 ± 0.0920 | 0.7528 | 0.5748 | 0.7059 | **0.7179** |
| Last-2 | **0.7439 ± 0.1033** | **0.7806** | **0.6123** | **0.7304** | 0.7203 |
| Last-2 − Frozen | **+0.0249** | **+0.0278** | **+0.0375** | **+0.0245** | +0.0023 |

Last-2 的平均分类结果具有实际幅度：macro F1、balanced accuracy、QWK 和普通 accuracy
均提高约 2.5–3.7 个百分点。类别层面，kitten recall 均为 0.9583，adult recall 均为
0.7167，senior recall 从 0.5833 提高到 0.6667，因此主要收益来自 senior。

配对方向呈混合分布：5/12 splits 提高、3/12 完全持平、4/12下降。按 repeat 汇总，差值为
`+0.0506、+0.0348、−0.0106`。两个 repeat 获得较明显提高，第三个 repeat 略低；这与早期
四折 pilot 中“有限解冻有信号、完整解冻易过拟合”的观察方向相容。

猫级 CE 从 0.7179 变为 0.7203，平均增加 0.0023。分类边界改善与概率质量因此没有同步；
Last-2 的 macro-F1 SD 也从 0.0920 增加到 0.1033。预设规则要求至少 8/12 提高并同时改善
猫级 CE，本轮分别得到 5/12 和 CE +0.0023，领域适配完整支持规则关闭。

Last-2 使用 14,276,355 个可训练参数，约为 frozen head 的 144 倍；训练累计 257.5 秒，
frozen 为 27.7 秒。它仍是一条值得保留的第二候选，但需要参数量匹配对照来判断 0.0249 的
中心增量来自 AST 顶层调整还是更大的优化空间。

## 5. 干扰变量信息

使用 frozen AST embedding 预测四个非年龄变量时，12 splits 的平均 validation R² 为：

| 变量 | Validation R² | 预测值与真实值 Spearman ρ |
| --- | ---: | ---: |
| log call duration | 0.7295 | 0.8869 |
| 有效 fbank 帧比例 | **0.8862** | **0.9436** |
| 平均绝对 fbank 值 | 0.7617 | 0.8645 |
| fbank 标准差 | 0.7832 | 0.8848 |

这些高数值说明 AST final embedding 同时保留了很强的时长、padding 和能量信息。它们可以
与年龄特征共存，也可能在小数据划分中形成捷径。后续局部分支或领域适配模块应报告这些变量
上的表现变化：理想模块会增强年龄分类，同时降低对偶然录音属性的依赖，或者至少保持依赖
程度稳定。

## 6. 阶段判断

三条完整支持规则均关闭，对应含义如下：

1. **中间层轴**：final layer 是明确的主表示，独立中间层和全层平均不进入优先路线；
2. **局部 patch 轴**：中频和中段时间形成两种稳定机制证据，完整增量仍需单模块检验；
3. **领域差异轴**：Last-2 有 0.0249 的分类中心收益和 senior recall 收益，split 一致性与
   猫级概率质量提供了清楚的改进目标。

按照阶段计划，当前 decision record 保持等待团队确认。我的优先级建议是：

1. **主方向：局部 patch**。设计一个保留 final global embedding 的轻量局部分支，只读取
   中频与相对时间结构，并避免 IDEA-052 的简单全时间均值；
2. **第二方向：有限领域适配**。保留 Last-2 结果，后续可设计参数更少的局部 adapter 或
   受约束 top-block 更新；
3. **暂缓：独立中间层融合**。L12 的独立表现和稳定性都更强，中间层只作为局部分支的可选
   输入来源。

若团队接受第一方向，下一步建立新的 Idea Card，并冻结 R0 原始 AST、M1 中频—时间局部
分支、C1 参数量匹配无局部机制对照。新的 IDEA 编号和继续门槛在查看 outer-test 前登记。
