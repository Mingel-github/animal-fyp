# IDEA-075：犬年龄任务 C1 年龄敏感 AST 跨物种探索结果

## 结论

IDEA-075 已完成预注册的 `135/135` 个神经网络 fits。独立只读审计从 135 份逐 fit 外层测试预测重新计算全部指标，所得 5 张汇总表、三层 gate 和原 `evaluation_summary.json` 的数值一致。

最终结论为：

1. **第一层 C1 整包相对 A0：FAIL。** C1−A0 的 9 个 `base_seed × split_repeat` 等权 Macro-F1 均值为 `+0.0002234`，是正值，但远低于预设的 `+0.005`；只有 `1/3` 个基础种子、`4/9` 个 seed×repeat、`7/15` 个共同 split-cell 为正。C1 的平均 CE 与 Brier 均略差于 A0。第一层失败。
2. **第二层有界机制相对 U1：不可解释／FAIL。** 第一层未通过，因此按预注册规则不能把第二层解释为机制确认。描述性地，C1−U1 Macro-F1 均值为 `-0.0009560`；不过 `5/9` 个 seed×repeat 为正，且 C1 的 CE、Brier 均优于 U1。这些正向概率质量信号保留，但不足以支持“有界机制优于无界残差”。
3. **第三层外部任务下限：PASS。** C1 在 `9/9` 个 seed×repeat 上都高于对应的完整 outer-train 类别先验 dummy；Macro-F1 优势均值为 `+0.1329640`，范围 `+0.1194819` 至 `+0.1442854`。

因此，本轮只能说：C1 在固定 2,290-bark-unit 犬子集上稳定高于训练先验基线，但没有稳定超过参数匹配 AST-only，也没有证明 RMS-relative tanh bound 优于无界年龄残差。**不升级 C1，不修改 cap、F0 范围、种子、切分、预算或 gate，也不进入完整 79,142-unit 犬 benchmark。**

## 研究边界

本轮测试的是一个有限的跨物种方法迁移问题：冻结 AST 表示与 20 维年龄敏感声学特征的 C1 有界残差融合，能否在犬只身份严格隔离的五分类年龄任务上超过 A0 与 U1。

- 数据为 IDEA-067 锁定的 2,290 个 bark units、125 只狗的资源受限子集，不代表完整 79,142-unit 数据。
- 标签直接使用数据提供方的 `age_group`：`puppy / juvenile / adolescent / adult / senior`；未依据月份重新分箱。
- 预测单位是 bark unit，切分与统计独立单位是 `dog_id`。
- 外层切分复用 IDEA-067 的 3×5 dog-grouped folds；每个 `base_seed × repeat` 合并 5 个 outer folds 后，形成 9 个等权主要分析单元。
- IDEA-067 的犬 AST-only 结果已被观察过，因此本轮即使过 gate 也只能算探索性跨物种支持，不是独立确认。

## `--resume` 异常审计

第二次相同命令加 `--resume` 时，runner 报告 `resumed aggregate differs from locked evaluation summary`。独立审计结论是：这是 **CRLF/LF 原始字节比较的跨平台误报**，不是实验结果或 JSON 语义漂移。

- 现有 `evaluation_summary.json` 为 8,611 bytes，SHA-256 为 `38651780226bd20561e04674201626e30ea4fc2c46183a738cc365fba8376125`。
- 文件包含 232 个 CRLF，且没有 lone LF。
- 将 CRLF 仅归一化为 LF 后，与同一 JSON 对象的 `json.dumps(..., indent=2, ensure_ascii=False) + "\n"` 字节完全一致。
- runner 先以 `read_bytes()` 读取现有 CRLF 文件，后以 LF 内存字节构造 `proposed` 并直接比较，因此在 Windows 写入产生 CRLF 时会误报。
- resume 过程中重新生成的 5 张汇总表、`fit_index.csv` 和 `pairing_audit.csv` 当前仍与原 evaluation summary 锁定哈希全部一致；135 个 fit summary 与 810 个核心工件哈希也全部通过，`*.tmp=0`。

本次没有修改协议或训练 runner，因为 runner SHA 已由协议锁定。新增的独立只读验证器承担跨平台复验：它不写 run 目录、不重新训练、不重新访问模型 test 推理路径，只读取已锁定工件并从逐样本预测复算。

因此需明确区分：

- **JSON 语义与实验工件一致性：通过。**
- **runner 的原始字节 resume guard：因 CRLF/LF 比较而误报，不能标为通过。**

该误报不使实验结果无效，但应在后续新协议版本中把字节比较改为明确的换行规范或语义比较；不能在本轮事后修改已锁 runner。
