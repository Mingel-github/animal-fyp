# IDEA-071：有界双路径年龄—AST 融合结果

## 结论

IDEA-071 的双路径候选 D1 没有通过预设 gate，也没有证据表明额外的通道缩放路径带来净收益。144/144 个 fits 完成后，D1 相对 A0 的 seed×repeat 平均 Macro-F1 差值为 `-0.0124345`，三个新基础种子上的平均差值全部为负，共同 split-cell 仅 `5/12` 非负，最差 split 为 `-0.1007957`。因此，D1 的基础有效性为 false，不能晋级。

与此同时，结果保留了两项有价值的结构信息：

1. 容量与约束匹配的有界加法对照 C1 相对原始 A1 平均提升 `+0.0169090`，9 个 seed×repeat 单元中 8 正、1 负，说明对加法残差进行有界化和容量控制，在这一组新种子上比无界 A1 更可靠。
2. 在 C1 上再加入逐通道 scale 后，D1−C1 为 `-0.0112208`，仅 2 正、2 平、5 负。额外 scale 路径没有提供净分类收益，反而抵消了有界 shift 的一部分优势。

D1 相对 A1 的替代性子门槛为 true：D1−A1 为 `+0.0056882`，且 pooled CE 更好。但这是因为本轮新种子上 A1 自身转为负向；D1 仍然低于 A0 和 C1，不能把“优于本轮 A1”包装成方法成功。整体判定保持为：基础有效性 false、A1 替代性 true、双路径机制 false、总 gate false。

## 研究问题与方法本质

前序结果提出了两种可能互补的年龄条件机制：

- 加法残差可以向 AST 表示补充新的年龄方向，但无界写入可能带来 split 敏感性和概率劣化；
- 有界通道缩放能重标定 AST 已有证据，校准表现较好，但纯缩放可能过于保守。

IDEA-071 检验：若把“补充新方向”和“缩放已有通道”合并为两个分别有界的路径，能否同时获得分类与校准收益。

共同 AST 主路径为：

```text
h = ReLU(W_ast x)
```

其中 `x` 是按训练角色标准化后的 768 维冻结 AST embedding，`a` 是锁定的 20 维 F0、周期性和音质特征。

### A0：AST-only

```text
h_A0 = h
```

### A1：原始无界加法残差

```text
c = GELU(W1 a)          # 20→32
r = W_r c               # 32→128
h_A1 = h + r
```

A1 可向 128 维隐藏空间加入任意方向和幅度的向量，表达能力强，但没有显式扰动上限。

### C1：有界宽加法对照

```text
c_wide = GELU(W_wide a)                         # 20→60
rms = stopgrad(sqrt(mean_j(h_j²) + 1e-8))
r_wide = 0.25 × rms × tanh(W_r_wide c_wide)    # 60→128
h_C1 = h + r_wide
```

C1 只保留 shift 路径，但扩大年龄编码器宽度以匹配 D1 容量，并使用 `tanh` 和相对 AST 隐状态 RMS 的固定上限。停止 `rms` 的梯度，避免主路径通过放大自身来间接放松约束。

### D1：有界 scale+shift 双路径

```text
c = GELU(W1 a)                                  # 20→32
s = 0.25 × tanh(W_s c)                          # 32→128
rms = stopgrad(sqrt(mean_j(h_j²) + 1e-8))
b = 0.25 × rms × tanh(W_b c)                    # 32→128
h_D1 = h × (1 + s) + b
```

D1 的 scale 把每个 AST 通道限制在原值的 `[0.75, 1.25]`，shift 则补充新方向，但每维幅度不超过当前样本隐藏 RMS 的 25%。两个输出头相互独立、共享 32 维年龄编码器，并全部零初始化。

## 参数匹配与归因设计

| 管线 | 总可训练参数 | 年龄分支参数 | 主要作用 |
|---|---:|---:|---|
| A0 | 99,075 | 0 | AST-only 对照 |
| A1 | 103,971 | 4,896 | 无界加法 shift |
| C1 | 108,143 | 9,068 | 有界、RMS 相对的宽 shift |
| D1 | 108,195 | 9,120 | 有界 scale + shift |

C1 与 D1 仅相差 52 个参数，并且匹配了年龄分支总容量、`tanh` 边界、`0.25` cap 和 RMS 相对 shift。因此，D1−C1 主要检验“额外 scale 路径”的机制贡献，而不是混入显著的参数量差异。

所有残差和调制输出层均为零初始化。同一 `(seed, repeat, fold)` 的四条管线从完全相同的优化前 logits 出发，并共享数据角色、AST 主头初始化、训练 RNG 重置、猫 batch 顺序、损失、优化器和 checkpoint 选择规则。

## 合并验证结果

| 管线 | Macro-F1 | Cross-entropy | Brier | Senior recall |
|---|---:|---:|---:|---:|
| A0 AST-only | 0.7304429 | **0.6918161** | **0.4114483** | 0.661111 |
| A1 无界加法残差 | 0.7129496 | 0.7176412 | 0.4249623 | 0.666667 |
| C1 有界宽加法 | 0.7298708 | 0.7119085 | 0.4229518 | 0.666667 |
| D1 有界双路径 | 0.7182453 | 0.6984165 | 0.4161628 | 0.644444 |

D1 的 pooled Macro-F1、CE 和 Brier 均劣于 A0，因此基础有效性层失败。相对 A1，D1 的 Macro-F1 和 CE 均更好，所以 A1 替代性子门槛通过；但这表示 D1 在这批种子上“比负向 A1 少退化”，不表示 D1 本身优于基线。

相对 C1，D1 的 Macro-F1 更低，但 CE 从 `0.7119085` 改善到 `0.6984165`，Brier 也从 `0.4229518` 改善到 `0.4161628`。额外 scale 路径可能仍具有置信度重标定作用，但没有转化为净分类收益，因此双路径机制不能晋级。

## A1 跨基础种子的结论更新

在 IDEA-071 之前，A1 对匹配 A0 的基础种子平均差值曾在 7/7 个已运行种子上为正：IDEA-068 的 seed 17，IDEA-069 的 `151`、`307`、`509`，以及 IDEA-070 的 `2326`、`3550`、`4426`。

本轮三个新种子的 A1−A0 平均差值均为负：

| 基础种子 | A1−A0 平均 Macro-F1 |
|---:|---:|
| 4412 | -0.029072 |
| 5703 | -0.021693 |
| 3120 | -0.003602 |

因此，“A1 在所有已测基础种子上都正向”的 7/7 叙述不再成立。按基础种子计，当前累计为 **7/10 正向、3/10 负向**。这些仍是同一数据集、相同内部角色上的初始化复验，不是 10 个独立数据集，也不能把 7/10 当作简单二项独立样本；但它足以推翻“A1 跨所有初始化始终正向”的过强表述。

这也改变了 D1−A1 的解释：D1 本轮平均优于 A1，主要说明有界结构在 A1 失效的种子上具有一定保护作用，而不是证明 D1 已取得绝对性能优势。

## 实际扰动强度

对每个 fit 的验证调用，记录年龄分支造成的相对扰动 `||h_fused−h|| / ||h||`：

| 管线 | 36 个 fit 均值的平均 | fit 均值范围 | 最大单 call |
|---|---:|---:|---:|
| C1 有界宽加法 | 0.05108 | 0.01514–0.07930 | 0.20355 |
| D1 有界双路径 | 0.05043 | 0.02042–0.07642 | 0.25820 |

C1 和 D1 的典型相对扰动都约为 5%，fit 均值也没有接近结构允许的理论边界。D1 的最大单 call 略高于 0.25，是因为该诊断衡量 scale 与 shift 合成后的向量相对范数，并不等同于任一单独路径的逐维 cap；不能据此认定单个路径越界。

因此，D1 的失败不能简单归因于“扰动过强”或“吃满了 0.25 上限”。更可信的候选解释包括：逐通道 scale 与 shift 在小数据下发生优化干扰、scale 路径增加了不必要的自由度，或两条路径对同一年龄线索进行了冗余修正。这些都只是结果后的机制解释，不能在当前结果上据此调参。

## 下一步建议

本轮结果不支持继续在 D1 上搜索 cap、宽度或双路径权重。更合理的后续方向是：

1. **回到 C1 做新的独立种子确认。** C1 在本轮相对 A1 为 `+0.0169090`、8/9 单元正向，并几乎恢复 A0 水平；但它尚未超过 A0，因此需要新的预注册种子验证，不能直接晋级。
2. **若再次研究 scale，应降低其自由度。** 可将 128 维逐通道 scale 改为单一全局标量、少数组 scale，或低秩 scale，使其承担校准而不与 shift 在每个通道竞争。
3. **采用预先锁定的分阶段启用。** 例如先训练有界 shift，再在固定 epoch 后启用 scale；这样可检验 scale 是提供增量校准，还是干扰已形成的年龄方向。
4. **保持结果边界。** 以上均应建立新协议和新种子，不能在当前 144 fits 上事后调节 `0.25` cap、隐藏宽度、启用时点或 gate。

当前应保留的模块级结论是：**有界化和容量控制相对本轮无界 A1 有价值；在匹配的有界 shift 上附加逐通道 scale 没有净分类收益。D1 不晋级，C1 仅作为下一轮独立验证候选。**
