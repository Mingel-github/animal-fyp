# IDEA-069：A1 年龄声学残差独立种子复现结果

## 结论

在三个预先锁定、且未用于 A1 的基础种子 `151`、`307`、`509` 上，A1「AST 隐状态 + 年龄敏感声学残差」相对匹配的 A0 AST-only 对照呈现了可复用的正向信号：9 个 seed×repeat 单元的平均 Macro-F1 差值为 `+0.010639`，3/3 个基础种子的平均差值均为正，9 个 seed×repeat 单元中有 6 个为正；合并验证预测的 Macro-F1 提升 `+0.009832`，senior recall 提升 `+0.033333`。

但是，A1 **没有通过预先锁定的稳健性门槛**。8 项 gate 中通过 5 项、未通过 3 项：共同 split 的非负比例不足，最差共同 split 超过允许的下降幅度，并且合并验证交叉熵劣于 A0。由于协议要求全部条件同时满足，本轮结论只能是：A1 存在跨种子的平均正向信号和后续可复用的机制价值，但当前证据不足以确认其为跨初始化稳健的改进，更不能包装成独立数据集确认。

## 实验目的与锁定比较

IDEA-068 在基础种子 17 上观察到 A1 的正向内部验证结果。IDEA-069 不改变模型、特征或超参数，只检验该结果能否在结果产生前已经选定的三个新基础种子上保持。

- `A0_ast_only`：冻结 AST 的逐叫声 embedding，使用标准化后的 `768→128→3` 分类头。
- `A1_age_residual`：在完全相同的 A0 主干上加入 `20→32→128` 年龄声学残差。
- 20 维年龄声学特征沿用 IDEA-068 已冻结的无标签 F0、周期性及音质统计，本轮没有重新选择特征、调整频率范围或改变网络宽度。
- A1 残差输出层严格零初始化，因此优化前 A0 与 A1 的 logits 必须逐元素相同。
- 两条管线在每个配对单元共享完整种子、数据划分和 batch 顺序，只使用 inner validation role，禁止访问 outer-test 预测。

总计算量为：

`2 pipelines × 3 base seeds × 3 repeats × 4 folds = 72 fits`。

## 统计口径与独立性

本报告严格区分四种汇总层级：

1. **3 个基础种子**：`151`、`307`、`509`。每个数值汇总该基础种子下的 3 repeats × 4 folds，用于判断增益是否跨初始化方向一致。
2. **9 个 seed×repeat 单元**：3 个基础种子 × 3 个 repeats；每个单元合并其 4 个 folds。这是平均增益、正向单元数等主要汇总口径。
3. **12 个共同 split-cell**：3 个 repeats × 4 个 folds；每个 split-cell 对三个基础种子的差值取平均，用于检验同一数据划分上的跨初始化稳定性。
4. **36 个逐 fold 配对结果**：3 seeds × 3 repeats × 4 folds，仅作描述。相同动物会跨种子和 repeat 重复出现，因此这 36 个差值不能视为 36 个独立样本。

合并验证结果中的 `612 animal occurrences` 同样不是 612 只独立动物。它是 9 个 seed×repeat 汇总中重复出现的验证动物记录（每个 seed×repeat 为 68 个动物出现次数，`68×9=612`）；同一动物跨种子和 repeat 被重复计入。因此，612 只能用于描述合并预测，不能当作独立样本量，也不能据此放大证据强度。

| 151 | +0.016326 | +0.083333 | 正向 |

| 509 | +0.011387 | +0.016667 | 正向 |

三个基础种子的 Macro-F1 平均差值全部严格大于 0。该结果表明，A1 的平均正向方向并非只由单个有利初始化种子造成；但种子 307 的增益较小，仍需结合 split 稳定性和概率指标判断。

### 九个 seed×repeat 单元

|---:|---:|---:|---:|
| 151 | +0.002939 | +0.009615 | +0.036424 |
| 307 | -0.011916 | -0.004127 | +0.028659 |
| 509 | +0.032870 | +0.025214 | -0.023923 |

- A0 平均 Macro-F1：`0.747780`。

- 9 个单元中 6 个正向、3 个负向，无平局；中位数差值为 `+0.009615`。
- 最佳单元为 `+0.036424`，最差单元为 `-0.023923`；差值样本标准差为 `0.021442`。

因此，seed×repeat 层面的中心趋势为正，且达到预设的 6/9 正向条件；同时，3 个负向单元说明改善尚非普遍发生。

## 预设 gate 逐项判定

协议规定所有条件必须同时满足。实际 8 项中通过 5 项、未通过 3 项：

| 预设条件 | 观察结果 | 判定 |
|---|---|---|
| 9 个 seed×repeat 的平均 Macro-F1 增益 ≥ `+0.005` | `+0.010639` | 通过 |
| 3/3 个基础种子的平均增益严格 > 0 | 151：`+0.016326`；307：`+0.004205`；509：`+0.011387` | 通过 |
| 至少 6/9 个 seed×repeat 增益严格 > 0 | `6/9` | 通过 |
| 至少 8/12 个共同 split-cell 的跨种子平均增益 ≥ 0 | `7/12` | **未通过** |
| 最差共同 split-cell 的平均增益 ≥ `-0.03` | `-0.038621 < -0.03` | **未通过** |
| 合并验证 cross-entropy 不劣于 A0 | A1 `0.689104 > 0.678878` A0 | **未通过** |
| 合并验证 Brier 不劣于 A0 | A1 `0.404709 < 0.404816` A0，轻微改善 | 通过 |
| 每个基础种子的 pooled senior recall 增益 ≥ `-0.02` | `+0.083333`、`0.000000`、`+0.016667` | 通过 |

总体 gate 判定为 **未通过**。按照锁定协议，本轮不得从结果中挑选有利种子，也不在同一结果上继续调整特征、超参数或门槛。

## 科学解释与后续价值

本次复现提供了两方面同时成立的证据。

第一，A1 具有值得保留的正向机制信号：三个基础种子的平均差值全部为正，seed×repeat 平均提升超过预设最低幅度，6/9 单元正向，合并 Macro-F1 与 senior recall 也均改善。这些结果支持继续把显式年龄声学特征作为 AST 的互补信息，用于后续机制消融、结构改进或冻结后的外部验证。

第二，当前 A1 还不能称为稳健或已确认的方法：5/12 个共同 split-cell 为负，最差共同 split 超出容许下降范围，且合并 CE 变差。也就是说，A1 更可能在部分划分中帮助分类边界，但尚未稳定改善概率质量和所有数据划分。

因此，本实验应被记录为：**未通过预设稳健性门槛，但存在跨种子、可复用的正向信号**。后续若继续，应先冻结新的改进方案和评价协议，再进行独立验证；本报告本身不构成确认性证据，也不构成独立数据集确认。
