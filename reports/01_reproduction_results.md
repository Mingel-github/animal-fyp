# VGGish Baseline 复现结果

日期：2026-08-25

## 复现范围

本次运行复现 van Toor 等人论文中的两个 VGGish 下游任务：

- 二分类（binary）：区分幼猫与老年猫，删除成年猫样本；
- 三分类（categorical）：区分幼猫、成年猫和老年猫。

两个任务均用于核对本机结果与原文结果是否一致。后续毕业设计的主要
baseline 和改进对象仍为更完整、更具挑战性的三分类任务。

## 来源与执行条件

- 上游提交：`3d02295bef1500d2b2500a124596f77010181391`
- 输入 CSV 的 Git blob：`947a7c9baa983c18009f2a85bc12d95e51fbd48b`
- 环境：Python 3.10.12、TensorFlow 2.15.0、CPU
- 随机种子：`7270`、`860`、`5390`、`5191`、`5734`
- 评估方式：每个 seed 执行 4 折 `StratifiedGroupKFold`，按 `cat_id` 分组
- 每个任务训练模型总数：20
- 最大训练轮数：1500 epochs；早停 patience：30

由于 Windows 证书库中的异常证书导致 Tornado/Jupyter 初始化时出现
ASN.1 错误，本次将 notebook 的代码单元按原顺序机械导出为 Python
脚本执行。模型结构、数据划分、seed、预处理、训练参数和指标计算代码
均未修改。

| 指标 | 原 notebook 保存结果 | 本机复现结果 | 差值 |
| --- | ---: | ---: | ---: |
| 总体 F1 | 71.8647% | 70.0136% | -1.8511 个百分点 |

五个 seed 的折平均 F1 分别为：

`0.708518`、`0.710271`、`0.678632`、`0.708859`、`0.694398`

20 个 fold 全部成功完成。早停发生在第 121～302 个 epoch，平均停止于
第 213.55 个 epoch，平均恢复到第 183.55 个最佳 epoch。模型代码报告的

本机三分类的类别宏平均准确率分别为：成年猫 69.96%、幼猫 81.64%、

更适合作为后续改进对象。

## 结论

二分类的总体 F1 和样本准确率与原 notebook 相差不到 0.1 个百分点，
可以认为完成了复现。

三分类结果比原 notebook 低约 1.4～2.4 个百分点，但总体性能水平、类别
表现和主要混淆关系一致。当前阶段将该差距视为随机训练、CPU 数值计算及
环境细微差异造成的偶然波动，不再为此增加额外排查步骤；本次结果可作为
有效复现结果和后续三分类 baseline。

需要记录的一个原代码细节是：上游 early stopping 监控训练集 `loss`，
而不是验证集损失，并恢复训练 loss 最佳时的权重。本次复现完全保留该行为。
后续可以重新考虑这一设计，但不修改上述 baseline 结果。
