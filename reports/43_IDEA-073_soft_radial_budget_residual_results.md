# IDEA-073：软径向预算宽年龄残差结果

## 结论

软径向预算候选 S1 获得了相对 A0 的正向平均信号，并成功保留了 U1 的分类能力下限，但没有通过整体 gate，也没有实现“兼得 U1 分类能力与 C1 概率质量”的预设目标。

在 9 个 seed×repeat 单元等权汇总下，S1−A0 的 Macro-F1 为 `+0.0056443`，达到最低效应门槛，且 6/9 个单元正向；12 个共同 split-cell 中也有 8/12 非负。然而，三个基础种子中只有一个正向、两个负向，最差 split 为 `-0.07129`，等权 CE 还比 A0 略高。因此，基础有效性层失败。

S1−U1 为 `-0.0040983`，仍在预设的 `-0.005` 非劣界以内，5/9 个单元非负，CE 和 Brier 均优于 U1，所以 U1 保留层通过。这是一项真实但有限的部分成功：软预算没有显著丢失 U1 的平均分类能力，并明显改善了其概率指标。

但 S1−C1 为 `-0.0191946`，三个基础种子均为负，9 个 seed×repeat 单元仅 3 个正向。尽管 S1 的 CE、Brier 均满足相对 C1 的预设容差，且 S1 的 Brier `0.4093558` 是四条管线中最低，C1 仍取得最高的平均 Macro-F1 `0.7705875`。C1 层因此失败。

最终状态为：基础有效性 false、U1 保留 true、C1 校准/分类结合层 false、总 gate false。S1 不晋级；不能把 U1 保留层通过或最低 Brier 包装成整体成功。

## 研究问题

IDEA-072 显示，U1 的宽无界加法具有较好的分类能力，而 C1 的逐维有界加法具有较好的概率质量。C1 使用逐维 `tanh`，不仅限制残差大小，还会因不同坐标压缩程度不同而改变原始残差方向。

IDEA-073 检验一个更精确的假设：如果保留 U1 学到的 128 维残差方向，只对整个残差向量的 L2 长度施加与 C1 相当的软预算，是否能同时保留 U1 的分类能力并接近 C1 的校准表现。

## 四条严格配对管线

共同 AST 主路径为：

```text
h = ReLU(W_ast x)
```

其中 `x` 是按训练角色标准化后的 768 维冻结 AST embedding，`a` 是固定的 20 维 F0、周期性和音质特征。

### A0：AST-only

```text
h_A0 = h
```

### U1：宽无界加法

```text
c = GELU(W1 a)       # 20→60
u = W_r c            # 60→128
h_U1 = h + u
```

U1 不限制残差 `u` 的方向或长度。

### C1：逐维有界宽加法

```text
q = stopgrad(sqrt(mean_j(h_j²) + eps))
r_C1 = 0.25 × q × tanh(W_r c)
h_C1 = h + r_C1
```

C1 独立压缩每个坐标。它能约束单维幅度，但通常会改变原始残差向量的方向。

### S1：软径向预算宽加法

```text
u = W_r c
B(h) = 0.25 × stopgrad(sqrt(sum_j(h_j²) + 128×eps))
||u|| = sqrt(sum_j(u_j²) + eps)
r_S1 = u × B(h) / (B(h) + ||u||)
h_S1 = h + r_S1
```

其中 `eps=1e-8`。S1 对 `u` 乘以一个正标量，所以在非零残差上严格保留方向；若令 `x=||u||/B`，则：

```text
||r_S1|| / B = x / (1 + x) < 1
```

当原始残差很小时，S1 接近 U1；当原始残差增大时，其长度平滑接近但不会越过预算。`B(h)` 停止梯度，防止 AST 主路径主动放大隐藏表示来放松预算。

## FP32 与 dtype epsilon 数值保护

S1 的范数、平方和、预算及缩放因子全部在关闭 autocast 的 FP32 区域中计算：先将 `h` 和 `u` 转成 FP32，再计算 `B(h)`、`||u||` 和软缩放。这样可避免混合精度下 `1e-8` epsilon 下溢，也降低 FP16 平方和溢出的风险。

在把 FP32 残差转换回隐藏表示 dtype 之前，程序还乘以：

```text
1 - finfo(h.dtype).eps
```

这一单 epsilon 向下保护用于防止接近预算的向量在 FP16 转换时因舍入而极小幅越界。FP32 下保护量约为 `1e-7`，FP16 下约为 `9.77e-4`。该保护不引入额外参数，不改变残差方向，只对最终长度做一个与 dtype 精度相匹配的微小下调。

## 科学解释与下一步判断

本轮给出的最强结论不是“S1 成功”，而是以下三点：

1. **软径向预算的工程实现是正确的。** 它保留方向、严格守住预算，FP32/dtype 保护有效，并未因接近饱和而退化。
2. **S1 部分保留 U1 的分类能力并改善校准。** U1 保留层通过，S1 的 CE 和 Brier 明显优于 U1，说明全局长度预算具有概率质量价值。
3. **保方向并没有超过逐维约束。** C1 取得本轮最高 Macro-F1，S1−C1 明显为负。原先“C1 因改变方向而损失分类”的假设没有得到支持；逐维压缩可能承担了有用的坐标选择和正则化作用。

因此，不应继续在本结果上调整 S1 的 `0.25` 预算、软缩放公式或非劣界。合理的下一步是：

- S1 保留为“方向保持、预算严格、校准较好”的机制消融，不晋级为主候选；
- 优先综合 IDEA-072 与 IDEA-073 的预注册 seed banks 评估 C1，而不是只选择本轮对 C1 有利的三个种子；
- 若 C1 的跨种子综合证据仍然可接受，再冻结结构进行外部数据或 AST 深度实验；
- 如继续研究新的约束形式，应另立协议检验分组或低秩的逐坐标约束，使模型保留 C1 的选择性，而不是围绕当前 S1 结果事后调预算。

当前应记录为：**S1 相对 A0 有正平均信号、U1 保留层通过且 Brier 最优，但基础稳健性与 C1 分类层失败，整体不晋级。C1 仍是本轮表现最强的分类候选。**

从本阶段开始，主候选结构冻结为：
