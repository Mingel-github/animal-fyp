# IDEA-070：有界年龄条件 AST 调制（BACM）结果

## 结论

有界年龄条件 AST 调制（B1/BACM）在校准与增益离散度上取得了正向结果，但没有通过预设的整体 gate，也不能替代原始的 A1 加法年龄残差。

相对 A0 AST-only，B1 在 9 个 seed×repeat 单元上的平均 Macro-F1 提升为 `+0.005090`，达到预设最低幅度；6 个单元正向、1 个平局、2 个负向，12 个共同 split-cell 中 9 个非负。合并预测中，B1 的 CE 为 `0.696422`、Brier 为 `0.411860`，均优于 A0 和 A1，说明其受限调制在概率质量上具有明确价值。B1−A0 的 seed×repeat 差值标准差为 `0.015556`，低于同批次 A1−A0 的 `0.019598`；但两者同为 6 正、1 平、2 负和 9/12 split 非负，且 B1 的最差 split 更低，因此不能笼统宣称 B1 已经比 A1 更稳定。

但 B1 的 seed×repeat 平均 Macro-F1 为 `0.741254`，明显低于 A1 的 `0.753736`；B1−A1 为 `-0.012483`，未达到预设的非劣界限 `-0.005`。此外，基础种子 3550 上 B1−A0 为 `-0.002904`，最差共同 split 为 `-0.037598`。10 项预设条件中通过 7 项、未通过 3 项，因此总体 gate 判定为未通过。

本轮最合理的科学解释是：BACM 的“只缩放已有 AST 通道”约束确实改善了校准，并缩小了 seed×repeat 增益的离散度，但没有减少同批次的负向单元，也没有改善最差 split；纯缩放对分类所需的新方向表达又过于保守。A1 的加法残差提供了 B1 不具备的表示方向能力。本结果是部分成功的方法证据，而不是 B1 已经通过、已经全面稳定化或已经取代 A1 的证据。

## 方法原理

设标准化后的 AST embedding 为 `x`，锁定的 20 维年龄声学特征为 `a`。三条严格配对管线共享 AST 主头：

```text
h = ReLU(W_ast x)
c = GELU(W1 a)
```

- `A0_ast_only`：`h` 直接经过 BatchNorm、dropout 和分类层。
- `A1_age_residual`：使用 `h + W2 c`。年龄分支可以向 128 维 AST 隐状态加入任意方向和幅度的向量。
- `B1_bounded_age_modulation`：

```text
s = 0.25 × tanh(W2 c)
h_B1 = h × (1 + s)
```

B1 的通道缩放因子被严格限制在 `[0.75, 1.25]`。它根据 F0、周期性和音质特征，对 AST 已经激活的证据通道做最多 ±25% 的增强或抑制；由于乘法发生在 ReLU 后，它不能翻转通道符号，也不能像 A1 那样凭空写入新的隐藏方向。

该结构的预期取舍是：牺牲一部分表达自由度，换取更小的扰动、更好的概率校准和更低的 split 敏感性。调制上限 `0.25` 在运行前锁定，本轮没有在观察结果后搜索其他幅度。

## 参数匹配与公平比较

A1 与 B1 使用完全相同的年龄分支尺寸：`20→32→128`。

| 管线 | 可训练参数量 | 年龄分支相对 A0 的新增参数 | 融合方式 |
|---|---:|---:|---|
| A0 AST-only | 99,075 | 0 | 无年龄分支 |
| A1 加法残差 | 103,971 | 4,896 | 任意方向加法 |
| B1 有界调制 | 103,971 | 4,896 | `[0.75, 1.25]` 通道缩放 |

新增的 4,896 个参数由 `20→32` 的 672 个参数和 `32→128` 的 4,224 个参数构成。因此，A1 与 B1 的差异来自融合算子，而不是参数预算。

A1 的残差输出层和 B1 的调制输出层均为权重、偏置零初始化。优化前 A1 的加法残差为 0，B1 的缩放残差 `s` 为 0，所以三条管线从完全相同的 logits 出发。每个 `(seed, repeat, fold)` 内还共享数据角色、AST 主头初始化、训练 RNG 重置、猫 batch 顺序、损失函数、优化器和 checkpoint 规则。

## 新种子与实验预算

本轮使用此前未用于 A1 的三个基础种子：`2326`、`3550`、`4426`。它们不是根据实验结果挑选，而是在运行前由固定字符串 `IDEA-070-bounded-age-conditioned-film-v1` 的 SHA-256 digest 确定：

```text
SHA-256 = 13179406c930b92e12db568abb716a965b9e8c15f16e1d233a6fc8eb9e555236
base seeds = [2326, 3550, 4426]
```

具体规则为：digest 的前三个大端 uint32 分别对 10000 取模。每个基础种子使用固定的 3 repeats × 4 folds，完整种子为 `base_seed + 10000×repeat + 100×fold`。

总预算为：

`3 pipelines × 3 seeds × 3 repeats × 4 folds = 108 fits`。

本实验只使用 inner train/validation roles，没有生成或访问 outer-test 预测。36 个逐 fold 比较以及合并预测中的 612 个 animal occurrences 会跨种子和 repeat 重复同一动物，只用于描述，不视为独立样本。

## 合并验证预测

| 指标 | A0 AST-only | A1 加法残差 | B1 有界调制 |
|---|---:|---:|---:|
| Macro-F1 | 0.737570 | 0.754357 | 0.741608 |
| Balanced accuracy | 0.769444 | 0.785185 | 0.776852 |
| Quadratic weighted kappa | 0.609398 | 0.629062 | 0.611462 |
| Plain accuracy | 0.718954 | 0.732026 | 0.723856 |
| Cross-entropy | 0.698851 | 0.707116 | **0.696422** |
| Brier | 0.417951 | 0.414571 | **0.411860** |
| Senior recall | 0.661111 | 0.666667 | 0.666667 |

B1 的 pooled Macro-F1 为 `0.741608`，高于 A0 的 `0.737570`，但低于 A1 的 `0.754357`。相反，B1 的 CE `0.696422` 同时优于 A0 的 `0.698851` 和 A1 的 `0.707116`；Brier `0.411860` 也同时优于 A0 的 `0.417951` 和 A1 的 `0.414571`。这正是本轮最清楚的部分成功：B1 没有取得 A1 的分类增益，却取得了三者中最好的合并概率指标。

B1 与 A1 的 senior recall 均为 `0.666667`，略高于 A0 的 `0.661111`。按基础种子汇总，B1−A0 senior recall 分别为 `+0.016667`、`-0.016667`、`+0.016667`，全部高于预设下限 `-0.02`。

## 预设 gate 逐项判定

协议要求全部条件同时满足。实际 10 项中通过 7 项、未通过 3 项：

| 预设条件 | 观察结果 | 判定 |
|---|---|---|
| 9 个 seed×repeat 的平均 B1−A0 Macro-F1 ≥ `+0.005` | `+0.005090` | 通过 |
| 3/3 基础种子的平均 B1−A0 严格 > 0 | 种子 3550 为 `-0.002904` | **未通过** |
| 至少 6/9 个 seed×repeat 的 B1−A0 严格 > 0 | 6 正、1 平、2 负 | 通过 |
| 至少 8/12 个共同 split-cell 的 B1−A0 ≥ 0 | `9/12` | 通过 |
| 最差共同 split-cell 的 B1−A0 ≥ `-0.03` | `-0.037598 < -0.03` | **未通过** |
| B1 pooled CE 不劣于 A0 | `0.696422 < 0.698851` | 通过 |
| B1 pooled Brier 不劣于 A0 | `0.411860 < 0.417951` | 通过 |
| 每个基础种子的 pooled senior recall 差值 ≥ `-0.02` | `+0.016667`、`-0.016667`、`+0.016667` | 通过 |
| 平均 seed×repeat B1−A1 ≥ `-0.005` | `-0.012483 < -0.005` | **未通过** |
| B1 pooled CE 不劣于 A1 | `0.696422 < 0.707116` | 通过 |

总体 gate 判定为 **未通过**。按照预先锁定的规则，本结果不能被称为“A1 的稳定化替代已经成功”，也不能在同一结果上继续调整调制上限、特征、宽度、种子或门槛。

## 方法解释与下一步建议

本轮结果支持两个互补判断。

第一，**有界调制在校准方向上明确成功，在方差控制上仅部分成功**。B1 相对 A0 的平均 Macro-F1 为正，B1−A0 的 seed×repeat 标准差低于同批次 A1−A0；更重要的是，B1 的 pooled CE 和 Brier 同时优于 A0、A1。这说明让年龄信息只负责重标定 AST 已有通道，可以形成更克制的概率输出。但 B1 与 A1 的正／平／负单元数及非负 split 数相同，B1 最差 split 还更低，不能把较小标准差扩大解释成全面稳定性提升。

第二，**纯缩放不足以替代加法残差的分类能力**。A1 在 seed×repeat 和 pooled Macro-F1 上都明显优于 B1。一个与结果一致的机制解释是：年龄相关声学线索不只需要回答“AST 的哪个已有通道应当放大或缩小”，还需要补充 AST 预训练表示中缺失的年龄方向。A1 可以增加新方向，B1 只能重加权已有方向，因此 B1 的增益离散度稍小、概率更易校准，却也更保守。

后续不应围绕本轮结果追调 `0.25` 上限。更合理的新实验应在新的锁定协议中同时保留两种能力，例如：

- 采用“较小的有界加法残差 + 有界通道缩放”，分别承担新方向补充与置信度调制；
- 对加法分支施加显式范数预算或门控，使其保留 A1 的表示能力，但限制极端 split 上的过度写入；
- 将 BACM 用作校准或辅助调制分支，而不是作为 A1 的完全替代，并在外部验证前重新进行独立种子筛选。

这些建议是基于本轮结果提出的下一轮假设，必须重新冻结结构与门槛后验证。当前结论保持为：**BACM 的校准方向成功、方差控制方向部分成功，但总体 gate 未通过，也不是 A1 的性能替代。**
