# IDEA-074：C1 × Hybrid Call+Cat 二乘二归因实验结果

## 结论

IDEA-074 已完成预设的 `144/144` 个 fits，四条管线各 36 个，全程只使用 inner train/validation roles，`outer_test_accessed=false`。

本轮三个预设层级均未通过，总 gate 为 false：

1. **C1 新种子复现失败。** `C1-C−A0-C` 的 seed×repeat 平均 Macro-F1 为 `-0.0125055`，9 个单元为 2 正、1 平、6 负，三个基础种子均为负；共同 split-cell 仅 `6/12` 非负，最差达到 `-0.1423120`。C1-C 的等权 CE 与 Brier 也都劣于 A0-C。第一层 gate 为 false。
2. **Hybrid 不并入 C1。** `C1-H−C1-C` 的平均 Macro-F1 为 `-0.0011060`，虽有 5/9 个 seed×repeat 正向，但只有 1/3 个基础种子正向、6/12 个 split 非负，最差 split 为 `-0.0690178`；CE 变差。Hybrid 监督下的表示比较 `C1-H−A0-H` 也为 `-0.0063234`，且 CE、Brier 均略差。第二层 gate 为 false。
3. **存在正平均交互方向，但不能宣称超加性协同。** 交互项 `I=(C1-H−C1-C)−(A0-H−A0-C)` 的平均值为 `+0.0061821`，5/9 个 seed×repeat 和 2/3 个基础种子非负；但只有 `7/12` 个共同 split-cell 非负，最差为 `-0.0681519`，第三层 gate 为 false。

因此，本轮**不把 C1-H 升级为主候选**。按预设规则，后续如继续该结构线，仍使用纯 `C1-C`，但其身份应从此前的“当前主要候选”下调为**仍保留的探索性候选**：历史综合方向仍略正，但本轮全新种子复现明确失败。Hybrid 保留为具有局部 Brier 与 senior recall 收益的监督消融，不并入主结构。

## 研究问题与方法本质

IDEA-071 至 IDEA-073 的综合证据曾支持把 C1 有界宽年龄残差设为当前主要候选；IDEA-066 的固定 Hybrid Call+Cat 监督也曾取得正向平均信号，但未满足全部稳定性门槛。本轮采用完整 2×2 设计，分别检验：

1. C1 在全新种子上能否继续超过匹配 A0；
2. Hybrid 监督能否在 C1 表示之上提供稳定增量；
3. Hybrid 对 C1 的增量是否大于对 A0 的增量，即是否存在超加性协同。

两个实验轴分别改变“如何把年龄声学信息写入 AST 表示”和“如何组合 call 级与 cat 级监督”。二乘二设计可以分离简单效应和交互项，但交互约为零不等于两个机制在数学意义上“不正交”。

### 表示轴：A0 与 C1

共同 AST 主路径为：

```text
h = ReLU(W_ast x)
```

其中 `x` 为仅使用训练角色统计量标准化的 768 维冻结 AST embedding，`a` 为锁定的 20 维 F0、周期性和声质特征。

A0 直接使用 AST 隐表示：

```text
h_A0 = h
```

C1 使用冻结的有界宽年龄残差：

```text
c = GELU(W_age a), W_age: 20→60
q = stopgrad(sqrt(mean_j(h_j²) + 1e-8))
r = 0.25 × q × tanh(W_r c), W_r: 60→128
h_C1 = h + r
```

C1 允许年龄声学支路向 AST 隐空间补充新方向，但每一维写入量相对当前样本 AST 隐状态 RMS 受到固定约束；`stopgrad` 防止主路径通过放大自身来间接放松预算。本轮没有调整 60 维宽度、`0.25` cap、特征集合或缺失值处理规则。

### 监督轴：Call-only 与 Hybrid

四条管线都计算类别平衡的 call 级交叉熵 `L_call` 与 cat 级交叉熵 `L_cat`。同一只猫的全部 calls 保持在同一个 set sample 中；cat 级概率是其 call softmax 概率的算术平均。call 权重只由训练 calls 计算，cat 权重只由训练 cats 计算，两项损失均在 batch 内按“加权和／权重和”归一。

```text
Call-only: L_C = L_call
Hybrid:    L_H = 0.5 × L_call + 0.5 × L_cat
```

Hybrid 不增加模型参数。它在逐条叫声判别之外，加入“同一只猫的多条叫声聚合后仍应判断正确”的动物级监督。固定 `0.5/0.5` 来自 IDEA-066，本轮没有搜索权重。

| 管线 | 表示 | 训练目标 | 可训练参数 |
|---|---|---|---:|
| `A0_C_call_only` | A0 AST-only | `L_call` | 99,075 |

同一完整种子下，A0-C 与 A0-H 的初始 `state_dict` 相同，C1-C 与 C1-H 的初始 `state_dict` 相同；共享 AST 主干张量一致，C1 年龄残差输出头零初始化，因此四条管线的优化前 logits 完全一致。四管线共享角色划分、猫 batch 顺序、call coverage、训练 RNG 重置、优化器、训练超参数和最低验证动物 CE checkpoint 规则。

## 新种子、预算与统计单位

固定 UTF-8 字符串 `IDEA-074-C1-hybrid-factorial-v1` 的 SHA-256 为：

```text
91d52a6aa12c7c8b7e37da71d0ece239c97564e6f3ae912ce92d60a9a07ab94a
```

预先锁定的基础种子为 `6346`、`7243`、`9617`。每个基础种子使用 3 repeats × 4 folds，总预算为：

`4 pipelines × 3 seeds × 3 repeats × 4 folds = 144 fits`。

Macro-F1、CE 和 Brier 的主要统计单位是 9 个 seed×repeat；每个单元先合并 4 folds，再等权平均。12 个共同 split-cell 由相同 repeat×fold 在三个基础种子上平均。36 个逐 fold 对比及每条管线 612 个重复 animal occurrences 只作描述，不视为独立样本。

“新种子复现”仍使用同一 111 只猫和相同内部角色系统，不是独立数据集确认。

## 二乘二交互项

Macro-F1 交互项定义为：

```text
I = (C1-H − C1-C) − (A0-H − A0-C)
```

其 seed×repeat 等权均值为 `+0.0061821`，方向为 5 正、0 平、4 负；3 个基础种子中 2 个非负，9 个 seed×repeat 中 5 个非负。这三项达到预设条件，说明 Hybrid 在 C1 上的相对边际效果平均优于它在 A0 上的边际效果。

但是，共同 split-cell 只有 `7/12` 非负，最差交互为 `-0.0681519`。所以该方向缺乏预设的跨 split 稳定性，不能表述为已确认的超加性协同。更保守的解释是：A0-H 本轮平均下降 `-0.0072881`，而 C1-H 相对 C1-C 只下降 `-0.0011060`，两者之差形成了正交互；这不等价于 C1-H 本身获得了绝对提升。

CE 改善量交互为 `+0.0027154`，Brier 改善量交互为 `+0.0053263`，senior recall 交互为 `+0.0055556`。这些描述指标也呈正平均方向，但不替代 Macro-F1 的 split 稳定性 gate。

## 正向结果的保留与边界

尽管总 gate 失败，本轮仍有以下正向结果：

1. Hybrid 在 C1 上的 Macro-F1 有 5/9 个 seed×repeat 为正，中位数为 `+0.0038668`；均值只小幅为负 `-0.0011060`，说明不是所有初始化都排斥 Hybrid。
2. `C1-H−C1-C` 的 Brier 改善量为 `+0.0022299`，6/9 个 seed×repeat 为正；pooled senior recall 提高 `+0.0222222`，三个基础种子的下降都没有超过 `-0.02`。
3. `C1-H−A0-C` 虽然平均分类和概率指标为负，但 senior recall 平均提高 `+0.0388889`，6/9 个单元为正；其 Brier 改善量也有 6/9 个单元为正，只是负向单元幅度使总体均值转负。
4. Macro-F1 交互均值为 `+0.0061821`，CE 与 Brier 改善量交互也分别为 `+0.0027154` 和 `+0.0053263`；说明 Hybrid 在 C1 上相对“少退化”或局部受益的方向值得后续机制研究。
5. C1-C 相对 A0-C 的 pooled senior recall 提高 `+0.016667`，三个基础种子均满足 senior recall 安全界限。

这些正向项的共同边界是：它们没有转化为稳定的平均 Macro-F1 优势。C1 复现、Hybrid 采用和协同的 split 稳定性均失败；因此不能只引用 Brier、senior recall、交互均值或有利 seed 来升级方法，也不应在本轮结果上事后调整 `0.5/0.5`、C1 cap、隐藏宽度、特征、种子、聚合单位或 gate。

## 科学解释与下一步判断

本轮最稳妥的判断是：

1. **C1 的历史平均信号仍可保留，但新种子复现失败。** 四轮描述性合并仍为 `+0.00505801`，然而 IDEA-074 的 3/3 基础种子均为负，说明 C1 对初始化和数据划分仍敏感，不能继续使用“已确认主候选”这一强表述。
2. **Hybrid 没有获得升级资格。** 它在 C1 上改善 Brier 和 senior recall，5/9 个 seed×repeat 的 Macro-F1 也为正，但平均分类与 CE、跨种子和跨 split 稳定性不足；所以不升级为 C1-H。
3. **正交互主要表示相对少退化，不是组合绝对成功。** 交互均值为正，是因为 Hybrid 在 A0 上平均下降更多，而不是 C1-H 已经超过 C1-C 或 A0-H。split 尾部失败进一步限制了协同表述。
4. **下一阶段停止在同一数据上围绕本结果调权重。** 若继续，冻结 C1-C 公式，把它与 A0 一起带到 CatMeows 和狗年龄 benchmark；外部数据若支持，才能提升其泛化可信度。Hybrid 可作为预设消融随行，但不作为主候选。若外部任务也失败，则 C1 仅保留为 MeowAgeNet 内部的探索性模块证据。

当前决策为：**继续保留 C1-C，候选级别下调；不升级 C1-H；不宣称超加性协同。**
