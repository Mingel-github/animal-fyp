# POST-IDEA-073：C1 主要候选与后续验证路线

## 阶段决策

IDEA-071 至 IDEA-073 的跨轮描述性证据支持将 C1 有界宽加法年龄残差设为当前主要候选。该决策不把任何历史 gate 改判为通过，也不授权在已观察结果上重新搜索 `0.25` cap、年龄分支宽度或20维特征集合。

冻结的 C1 为：

```text
h = ReLU(W_ast x)
c = GELU(W_age a), W_age: 20→60
r = 0.25 × stopgrad(RMS(h)) × tanh(W_r c), W_r: 60→128
h_C1 = h + r
```

## 第一阶段：C1 × Hybrid Call+Cat 的二乘二归因实验

Hybrid Call+Cat 在 IDEA-066 中平均改善 Macro-F1、CE 和 Brier，但 split 稳定性不足。它改变的是监督层级，C1 改变的是表示融合，两者机制正交。下一轮不只训练一个“C1+Hybrid”组合，而使用完整二乘二矩阵：

| 表示模块 | Call-only loss | Hybrid call+cat loss |
|---|---|---|
| A0 AST-only | A0-C | A0-H |
| C1 有界年龄残差 | C1-C | C1-H |

Hybrid 固定为 IDEA-066 的 `0.5×call CE + 0.5×cat CE`，不得在本轮搜索混合系数。C1 完全复用冻结公式。四条管线共享新种子、数据角色、初始化、batch 顺序、优化器和 checkpoint 规则。

本轮同时回答三个问题：

1. C1-C 是否继续超过 A0-C；
2. C1-H 是否超过当前主候选 C1-C；
3. 交互项 `(C1-H−C1-C)−(A0-H−A0-C)` 是否为正，即 Hybrid 是否对 C1 提供超出其对 A0 的增量价值。

主要判断仍以 seed×repeat 等权 Macro-F1 为主，并同时检查 CE、Brier、共同 split、最差 split 和 senior recall。只有 C1-H 相对 C1-C 达到预注册最低效应、跨种子方向和稳定性条件，才把 Hybrid 并入主候选；否则继续保留纯 C1。

## 第二阶段：外部 benchmark

完成内部二乘二归因后，冻结胜出的 C1 版本，不再针对外部数据改变融合公式。

### 犬年龄阶段：直接年龄迁移

这是更直接的外部年龄验证。使用严格按 `dog_id` 隔离的分组交叉验证，对比：

- 外部 A0：冻结 AST 表示；
- 外部 U1：参数匹配的无界宽年龄残差；
- 外部 C1：冻结公式的有界宽年龄残差；
- 训练折类别先验 dummy。

第一步复用已审计的 2,290 样本固定子集验证执行链和特征覆盖；资源允许时再建立完整犬数据协议。主要指标为 Macro-F1 和 balanced accuracy，重点报告 senior 类召回与跨犬方向。犬实验失败时，不宣称 C1 学到了通用跨物种年龄表示。

### CatMeows：未见猫情境保持性

CatMeows 没有猫年龄标签，因此它不是年龄有效性验证。这里使用严格按猫隔离的情境分类，比较 A0 与同结构 C1，回答年龄声学分支是否损害 AST 原有的跨猫情境表示。

若 C1 不降低情境 Macro-F1，可称其在加入年龄归纳偏置后保留通用情境信息；即使提高情境分类，也不能表述为猫年龄外部验证。

## 第三阶段：AST 内部化改进

只有当 C1 在内部归因或外部年龄任务上保持正向后，才考虑把年龄条件从分类头后融合推进到 AST 内部。优先测试单一、参数匹配的末层注入位置，而不是同时搜索多层位置、cap 和宽度：

1. 在最后一个 AST block 输出后加入冻结公式的 C1 residual；
2. 使用相同参数量、但只在分类头处加入 C1 的控制组；
3. AST 主体保持冻结或只开放明确的一小部分归一化参数；
4. 只有内部注入相对头部 C1 获得稳定增益，才称为“改进 AST 本身”。

## 停止与保留规则

- 不再进行只有新随机种子、没有新科学问题的重复；同数据集追加种子只能服务于明确的确认协议。
- 不在当前 MeowAgeNet 结果上调整 C1 cap、宽度或特征集合。
- C1-H 若失败，保留 C1-C；不根据有利 split 改混合权重。
- 犬年龄若失败，C1 仍可保留为猫数据内部候选，但不得扩大为跨物种年龄方法。
- CatMeows 只用于情境表示保持性，不用于年龄主张。
- S1、B1、U1 和 A1 均保留为论文消融：分别代表径向预算、乘法调制、无界宽残差和原始窄残差。

## 推荐执行顺序

```text
C1 候选冻结
  → C1 × Hybrid 二乘二归因
  → 冻结胜出版本
  → 犬年龄直接外部验证
  → CatMeows 情境保持性验证
  → 条件满足后再测试 AST 末层内部注入
```

这一顺序先解决“方法是否互补”，再解决“能否迁移”，最后才增加 AST 内部结构复杂度，避免在同一小数据集上继续堆叠模块。
