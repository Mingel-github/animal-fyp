# IDEA-073：软径向预算宽年龄残差

## 研究问题

IDEA-072 给出了一个清晰的权衡：宽无界残差 U1 的 seed×repeat 平均 Macro-F1 最高，相对 A0 为 `+0.010692` 且三个基础种子均为正；有界 C1 的平均 Macro-F1 略低，但 Brier 为四者最佳，CE 也明显优于 U1。C1 的逐维 `tanh` 同时限制残差大小和改变残差方向，可能是分类性能略降的原因。

本轮检验一个新的模块级假设：保留 U1 学到的128维残差方向，只对残差整体长度施加与 C1 相同的软预算，能否保留 U1 的分类能力并获得 C1 的概率质量。

## 四条配对管线

共同 AST 主路径：

```text
h = ReLU(W_ast x)
```

其中 `x` 为训练角色标准化的768维冻结 AST embedding，`a` 为锁定的20维年龄声学特征。

### A0：AST-only

```text
h_A0 = h
```

### U1：宽无界加法

```text
c = GELU(W1 a), W1: 20→60
u = W_r c, W_r: 60→128
h_U1 = h + u
```

### C1：逐维有界宽加法

```text
c = GELU(W1 a)
q = stopgrad(sqrt(mean_j(h_j^2) + eps))
r_C1 = 0.25 * q * tanh(W_r c)
h_C1 = h + r_C1
```

### S1：软径向预算宽加法

```text
c = GELU(W1 a)
u = W_r c
B(h) = 0.25 * stopgrad(sqrt(sum_j(h_j^2) + 128*eps))
u_norm = sqrt(sum_j(u_j^2) + eps)
r_S1 = u * B(h) / (B(h) + u_norm)
h_S1 = h + r_S1
```

`eps=1e-8`。S1 不逐维裁剪，因此 `r_S1` 与原始残差 `u` 保持相同方向；当 `||u||` 远小于预算时，S1 近似 U1；当 `||u||` 变大时，残差范数平滑饱和，并严格满足：

```text
||r_S1||_2 < B(h)
```

`B(h)` 与 C1 在128维下允许的最大 L2 残差预算一致。它停止梯度，防止 AST 主路径通过主动放大 `h` 来放松预算。

为避免混合精度下 `eps` 下溢或平方和溢出，`h`、`u` 的范数、预算和缩放因子必须在关闭 autocast 的 FP32 区域计算；最终 `r_S1` 乘以 `1-finfo(h.dtype).eps` 的单 epsilon 向下保护，再转换回 `h` 的 dtype 后相加。这防止接近饱和的向量在 FP16 转换时因舍入而极小幅超过预算；FP32 下该保护约为 `1e-7`，FP16 下约为 `9.77e-4`。这是锁定于评估前的数值稳定措施，不改变模型参数、方向或理论预算。

## 参数与初始化公平性

| 管线 | 总可训练参数 | 年龄分支参数 |
|---|---:|---:|
| A0 | 99,075 | 0 |
| U1 | 108,143 | 9,068 |
| C1 | 108,143 | 9,068 |
| S1 | 108,143 | 9,068 |

U1、C1、S1 使用完全相同的 `20→60→128` 参数结构。三个年龄输出头均为权重和偏置零初始化；同一完整种子下，三者初始 `state_dict` 必须逐张量相同，四条管线的优化前 logits 必须完全一致。构造模型后重置训练 RNG，确保猫 batch 顺序、dropout/AMP 随机流、损失、优化器和 checkpoint 规则严格配对。

## 新种子与预算

固定 UTF-8 字符串：

```text
IDEA-073-soft-radial-budget-wide-residual-v1
```

SHA-256：

```text
2652b329ce659a3e45984fdda294bb55bb78e682375e7c595831c0e1624199f5
```

按连续大端 uint32 对10000取模并跳过冲突值，前三个值无冲突：

```text
base seeds = [4025, 5118, 9821]
```

这些种子未用于 IDEA-068 至 IDEA-072。固定3 repeats × 4 folds，完整种子为 `base_seed + 10000×repeat + 100×fold`。

总预算：`4 pipelines × 3 seeds × 3 repeats × 4 folds = 144 fits`。

这里的“新种子”仍复用相同111只猫和内部角色，并非独立数据集验证。

## 预设 gate

Macro-F1、CE、Brier 均以9个 seed×repeat 单元等权汇总；每个单元先合并四折。12个 split-cell 先跨三个基础种子平均。36 folds及612个重复 animal occurrences只作描述。

### 基础有效性：S1 对 A0

1. 平均 S1−A0 Macro-F1 至少 `+0.005`；
2. 3/3 基础种子的平均 S1−A0 严格大于0；
3. 至少6/9个 seed×repeat 的 S1−A0 严格大于0；
4. 至少8/12个共同 split-cell 的 S1−A0 不小于0；
5. 最差共同 split-cell 不低于 `-0.03`；
6. S1 的等权平均 CE 与 Brier 均不劣于 A0；
7. 每个基础种子的 pooled senior recall 相对 A0 不低于 `-0.02`。

### 保留 U1 分类能力

8. 平均 S1−U1 Macro-F1 不低于非劣界 `-0.005`；
9. 至少5/9个 seed×repeat 的 S1−U1 不小于0；
10. S1 的等权平均 CE 与 Brier 均不劣于 U1。

### 保留 C1 概率质量并改善分类

11. 平均 S1−C1 Macro-F1 严格大于0；
12. 至少2/3基础种子的平均 S1−C1 不小于0；
13. 至少5/9个 seed×repeat 的 S1−C1 不小于0；
14. S1 的等权平均 CE 不高于 C1 `+0.005`；
15. S1 的等权平均 Brier 不高于 C1 `+0.002`。

CE `+0.005` 与 Brier `+0.002` 是在看到 IDEA-072 后、运行 IDEA-073 前锁定的探索性校准非劣容差，约占当前指标尺度不到1%；它们允许用极小概率质量代价换取分类收益，不等同于“绝对不劣于 C1”。

全部三层通过才称 S1 实现“U1分类能力与C1概率质量的软预算结合”。若仅基础层通过，只称 S1 整包模块有效；若 U1 层失败，说明软预算损失分类能力；若 C1 层失败，说明没有保住有界模块的校准优势。

## 审计与停止边界

- 只使用 inner train/validation roles，禁止生成 outer-test 预测；
- 锁定 roles、AST embedding、AST fbank、年龄特征和提取摘要哈希；
- 核对792 calls、111 cats、36个互不重复的完整种子；
- 核对 U1、C1、S1 初始 `state_dict` 逐张量相同以及36组优化前 logits 差为0；
- 共同 epoch 的猫顺序与 call coverage 哈希必须一致；
- 记录 C1 与 S1 最终 checkpoint 的 `||r||/||h||`；S1 另记录 `||u||/B`、`||r||/B`、方向余弦和接近饱和比例，并验证每个验证 call 均未超过预算。这些只用于机制审计，不参与选模；
- 无论结果如何，不在本结果上调整公式、`0.25`预算、宽度、种子、非劣界或 gate。
